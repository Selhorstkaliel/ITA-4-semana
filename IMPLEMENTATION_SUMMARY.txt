PROJECT OVERVIEW
================================================================================
A complete forum web application built using Java Servlets, JSP, and JDBC
following the MVC (Model-View-Controller) architecture pattern.

================================================================================
- Java 8
- Servlet API 3.1
- JSP 2.3 with JSTL 1.2
- JDBC with MySQL 8.0
- Maven 3.x (Build Tool)
- JUnit 4.13.2 (Testing)
- DBUnit 2.7.3 (Database Testing)
- Selenium 4.11.0 (UI Testing)
- Apache Tomcat 8.5+ (Application Server)

DATABASE SCHEMA
================================================================================

TABLES:
1. user
   - id (PK, AUTO_INCREMENT)
   - name (VARCHAR)
   - login (VARCHAR, UNIQUE)
   - email (VARCHAR)
   - password (VARCHAR)
   - points (INT)
   - created_at (TIMESTAMP)

2. topic
   - id (PK, AUTO_INCREMENT)
   - title (VARCHAR)
   - content (TEXT)
   - user_id (FK -> user.id)
   - created_at (TIMESTAMP)

3. comment
   - id (PK, AUTO_INCREMENT)
   - content (TEXT)
   - topic_id (FK -> topic.id)
   - user_id (FK -> user.id)
   - created_at (TIMESTAMP)

RELATIONSHIPS:
   - topic.user_id -> user.id (ON DELETE CASCADE)
   - comment.topic_id -> topic.id (ON DELETE CASCADE)
   - comment.user_id -> user.id (ON DELETE CASCADE)

DEPLOYMENT
================================================================================

Requirements:
   - Java 8 or higher
   - MySQL 5.7 or higher
   - Apache Tomcat 8.5 or higher
   - Maven 3.6 or higher (for building)

Quick Deploy:
   1. Setup MySQL databases (forum_db, forum_db_test)
   2. Run schema script
   3. Build: mvn clean package
   4. Deploy: cp target/forum.war $CATALINA_HOME/webapps/
   5. Access: http://localhost:8080/forum
